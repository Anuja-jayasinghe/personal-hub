Glass icons, one colour per part of the hub

A frosted glass plate over a coloured shape, with the line glyph and terminal dot of the Switchboard icons on top. Each part of the hub owns one colour and one back shape, so it is recognisable before you read the name. Glass is for identity (navigation, module headers, the home screen), never for data.

At small sizes the glass and the colour shape shrink together, so the navigation keeps its colour code. Data (units, money, dates) stays on plain faceplates in ink, red and the status lamps, which keeps the screen readable.
